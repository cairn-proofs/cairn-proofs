- [ ] 3.4 Add the snapshot and restore logic to `tools/update_deps.py` (design Decision 6). It restores both files in a `try`/`finally` block, maps SIGTERM and SIGHUP to `KeyboardInterrupt`, stops the running child before it restores, writes each restored file through a temporary file, `fsync` and `os.replace`, and still restores the second file when the first restore fails. Tests: each failure and signal case leaves both lockfiles byte-identical; a second concurrent run stops. Scenarios: [TOOLS-016.03], [TOOLS-016.04], [TOOLS-016.05], [TOOLS-016.06].
- [ ] 3.5 Add the resolution steps to `tools/update_deps.py` (design Decisions 5, 10, 11 and 12). Tests with a fake runner: a failure at each step restores; a direct dependency that crosses a major version fails; a source-only package fails and is named; the uv and npm commands carry the expected options.
